# Culling Bay for iPhone

A native SwiftUI app over the photo server's `/m/api` routes (`review/API.md`). The server
on the PC keeps doing everything it does now (NAS, RAW decodes, search, Lightroom). The app is
a better front end. The web pages under `/m` stay as a fallback.

Scope and decisions: https://claude.ai/artifact/FQv95YRVDg1DK6tBvruvob (picks made 2026-10-17).

## Layout

- `CullingBayCore/`: Swift package with no UI. It holds the models, the API client with ETags,
  save options, Server-Timing parsing, timing reports, and zoom tile planning. It builds and tests
  on Linux (the PC) and on the Mac. See its README.
- `CullingBay/` *(from Monday)*: the SwiftUI app target, generated by XcodeGen from `project.yml`,
  importing `CullingBayCore`.

## Building on the Mac (Monday)

The PC writes the code; the Mac compiles it over SSH. The Mac is `100.64.156.37` on Tailscale
(ssh with `-o HostKeyAlias=192.168.1.75`).

1. Check `xcodebuild -version`, and install XcodeGen (`brew install xcodegen`) if it's missing.
2. Run `swift test` in `CullingBayCore` on macOS as well.
3. Build the app without signing, then package an .ipa for the phone's re-signing tool:

       xcodegen generate
       xcodebuild -project CullingBay.xcodeproj -scheme CullingBay -configuration Release \
         -sdk iphoneos -archivePath build/CullingBay.xcarchive archive \
         CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO
       mkdir -p build/Payload && cp -R build/CullingBay.xcarchive/Products/Applications/CullingBay.app build/Payload/
       (cd build && zip -qr CullingBay.ipa Payload)

4. Simulator screenshots (`xcrun simctl io booted screenshot`) let the screens be checked before an install.

Info.plist needs:
- an App Transport Security allowance for plain HTTP to the PC (N4);
- `NSPhotoLibraryAddUsageDescription`, because saving asks only for add-only access to Photos.

A free Apple ID allows a limited number of app IDs, so phase 4's widget (an app extension with an
App Group) needs checking against Danny's re-signing setup before it's built.
